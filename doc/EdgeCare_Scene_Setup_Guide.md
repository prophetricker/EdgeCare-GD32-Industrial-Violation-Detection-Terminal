# EdgeCare Dangerous-Zone Scene Setup Guide

## 目标

队友当前只负责把后续要拍摄的固定机位危险区场景搭建好，不负责训练模型或修改固件。

场景搭建完成后，应保证同一套布置能重复拍摄：

- `empty/safe`：危险区内无人。
- `intrusion`：人员进入危险区。
- 相机位置、危险区边界和主要照明可以恢复到同一状态。

当前 OV5640 图像链路还在诊断阶段，因此现阶段只做空间、机位和照明准备，不把手机照片当成正式训练数据。

## 推荐场景

优先搭建一个简化工业危险区，例如：

- 设备检修区。
- 机械臂工作区。
- 高压设备隔离区。
- 仓储搬运禁入区。

不需要真实工业设备。可以使用纸箱、工具架、桌椅、警示牌和胶带形成可信的演示环境，但画面中应有明确的“危险设备”和“禁止进入区域”两个视觉要素。

## 场地要求

- 使用室内固定区域，避免每天移动背景。
- 危险区建议至少能容纳一个人完整站立或半身进入。
- 使用红白或黄黑警示胶带标出边界。
- 背景不要只有纯白墙，放置少量固定工业道具，增强场景辨识度。
- 清理会频繁移动的杂物，避免模型只学到物品变化。
- 保留人员从区域外走入危险区的通道。

尺寸可以按场地缩放，但必须记录：

```text
危险区长度：
危险区宽度：
相机到危险区中心的水平距离：
相机离地高度：
相机俯角：
人员主要进入方向：
```

## 相机机位

最终数据集必须尽量来自项目实际使用的 OV5640。现阶段可以用手机预览构图，但手机不能替代最终 OV5640 数据。

机位要求：

- 使用支架固定，不能手持拍摄。
- 危险区占画面面积建议为 `30%-60%`。
- 画面中同时保留区域边界和人员进入通道。
- 避免相机正对强光或窗户。
- 避免危险区被桌面、护栏或大型物体完全遮挡。
- 在地面标记支架脚位置。
- 记录镜头朝向、高度和俯角。

建议拍三张手机预览图用于讨论：

```text
scene_empty_preview.jpg
scene_intrusion_center_preview.jpg
scene_intrusion_edge_preview.jpg
```

这些图片只用于确定构图，通过聊天工具或网盘传递，不提交 Git 仓库。

## 光照

至少准备两种可重复条件：

1. 正常室内灯光。
2. 较暗或侧光条件。

要求：

- 不使用会明显频闪的廉价调光灯。
- 记录开了哪些灯、窗帘是否拉上。
- 正式训练和测试都应包含光照变化。
- 不要为了让模型容易分类，故意让 `empty` 全在白天、`intrusion` 全在晚上。

## 人员姿态清单

场景完成后，确认空间允许拍摄这些姿态：

- 正面进入。
- 侧面进入。
- 背面进入。
- 只进入半个身体。
- 站在危险区边缘。
- 蹲下或弯腰。
- 快速经过。
- 穿深色和浅色衣服。

负样本还需要覆盖：

- 区域外有人经过。
- 危险区内无人但背景有轻微变化。
- 门、窗帘或显示器画面变化。
- 区域边缘放置工具或纸箱。

## 防止数据泄漏

正式采集时不能简单地从一段连续视频中随机抽帧，再随机拆成训练集和测试集。相邻帧过于相似，会产生虚高准确率。

后续应按拍摄批次拆分：

```text
session_01 -> train
session_02 -> validation
session_03 -> test
```

每个 session 应重新让人员离开再进入，并适当改变衣服、站位或光照。最终测试集必须来自实际 OV5640，不使用手机图替代。

## 队友交付内容

场景搭建完成后，队友只需要回传：

1. 一张场景俯视草图，标出相机、危险区和人员进入方向。
2. 三张手机预览图：空场景、区域中心闯入、区域边缘闯入。
3. 场景尺寸和相机机位记录。
4. 可用灯光条件。
5. 可以拍摄的人员姿态清单。
6. 当前缺少的支架、胶带、灯光或道具。

验收标准：

- 相机机位能够固定和复现。
- 危险区在画面中清晰可见。
- 人员进入后不会被大面积遮挡。
- 空场景与闯入场景的唯一主要差异是人员是否进入危险区。
- 场景允许后续使用同一 OV5640 连续采集 `empty/safe` 和 `intrusion`。

## 暂停事项

在项目负责人确认 OV5640 输出为真实有效画面前，队友暂时不要：

- 批量拍摄训练图片。
- 手工缩放手机照片作为最终数据集。
- 开始标注大量图片。
- 训练模型并报告准确率。
- 修改 GD32H759 固件和 Keil 工程。
